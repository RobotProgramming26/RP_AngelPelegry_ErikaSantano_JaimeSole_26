# ROS1 Robot Factory Game

This repository contains a small Pygame game connected to ROS1. The player provides their details, moves a character with the keyboard, and receives a final score when the game ends.

## Packages

- game_msgs defines the custom GameUserMsg message.
- game_pr contains the four ROS nodes.

The workspace also includes the recorded demonstration, GAMEPLAY_ROS.mp4. It is stored using Git LFS, so install Git LFS and run git lfs pull if the video does not download with the repository.

## ROS nodes and communication

| Node | Purpose |
|---|---|
| info_user_node | Requests the player's full name, username, and age, then publishes them. |
| game_node | Runs the game, receives player details and movement commands, and publishes the final score. |
| control_node | Reads arrow-key or WASD input and publishes movement commands. |
| result_node | Receives the player's username and final score, then prints the result. |

The nodes communicate through these topics:

| Topic | Message type | Direction |
|---|---|---|
| /user_information | game_msgs/GameUserMsg | info_user_node publishes player details; game_node and result_node subscribe. |
| /keyboard_control | std_msgs/String | control_node publishes UP, DOWN, LEFT, or RIGHT; game_node subscribes. |
| /result_information | std_msgs/Int64 | game_node publishes the final score; result_node subscribes. |

GameUserMsg contains name (string), username (string), and age (int64). The game runs through Welcome, Game, and Final phases.

## Requirements

- ROS Noetic on Ubuntu 20.04
- Python 3
- Pygame 2.6.1
- WSL 2 with WSLg, or another Linux display server, if running the graphical game from WSL

Install the required tools and Pygame:

bash
sudo apt update
sudo apt install -y python3-pip git-lfs
python3 -m pip install --user --upgrade pygame==2.6.1
git lfs install
git lfs pull


The Pygame version matters: the game uses rounded rectangles, which require Pygame 2.

## Build

From the Catkin workspace root, run:

bash
source /opt/ros/noetic/setup.bash
catkin_make
source devel/setup.bash


Run the two source commands again in each new terminal before starting a node.

The repository includes build/ and devel/ snapshots. These folders are generated by Catkin and may contain paths from the machine where they were created, so rebuild the workspace with catkin_make before running it in another environment.

## Run the game

Open five terminals. In each terminal, source ROS and the workspace:

bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash


Then run one command in each terminal, in this order:

**Terminal 1 — ROS master**


roscore

**Terminal 2 — result display**


rosrun game_pr result_node.py


**Terminal 3 — game window**


rosrun game_pr game_node.py


**Terminal 4 — keyboard controller**


rosrun game_pr control_node.py


**Terminal 5 — player information**


rosrun game_pr info_user_node.py


Enter a full name, username, and positive age when prompted. Once the game starts, use the arrow keys or W/A/S/D in the keyboard-controller terminal to move. The result node prints the username and final score when the game ends.

Press Esc in the game window to exit, or use Ctrl+C in the node terminals. Stop roscore last.
